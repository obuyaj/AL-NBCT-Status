# 🎓 Education Equity Analysis in Alabama

This project explores the **distribution of National Board-Certified Teachers (NBCTs)** across Alabama counties and their correlation with **socio-economic indicators** and **student performance**. It was conducted as part of a data analytics capstone and contributed insights to the **Huntsville Committee 100's "Raise Your Hand" campaign**.

---

## 📊 Project Objectives

- Analyze the **geographic distribution** of NBCTs in Alabama.
- Examine correlations between:
  - NBCT ratios and student performance (Grade 3 reading levels).
  - NBCT presence and socio-economic factors (free/reduced lunch eligibility).
- Provide **data-driven recommendations** for improving education outcomes.
